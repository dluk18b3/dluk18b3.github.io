# App Privacy Policies

Public privacy policies hosted with GitHub Pages.

- [Call Guard](https://dluk18b3.github.io/call-guard/privacy/)
- [Dramory](https://dluk18b3.github.io/dramory/privacy/)

## Publishing

GitHub Pages publishes the root of the `main` branch.

- Edit `call-guard/privacy/index.html` to update the Call Guard policy.
- Edit `dramory/privacy/index.html` to update the Dramory policy.

## Source

The initial Call Guard policy was copied verbatim from the [existing Google document](https://docs.google.com/document/d/1ZPT1UBDL1mTGWS35sxiJAa00kTidY_nTW-p6Z9-IA3U/edit), with a revision date of 2 October 2026. Only HTML formatting and clickable links were added.

The initial Dramory policy was copied verbatim from the [existing Google document](https://docs.google.com/document/d/195gwZIzRg9hbQLEszIgksvShKyNZDSN9uPSILdBYLoI/edit), with an effective date of September 20, 2026. Only HTML formatting was added.

Subsequent policy revisions are recorded in Git history.
